# Advanced Data Mining — Lab Reports

Lab reports for **732A75 Advanced Data Mining** at Linköping University. All labs are solved with the **Weka** data mining toolkit, covering unsupervised learning and pattern mining.

| Lab | Report | Topic | Dataset |
|---|---|---|---|
| 1 | [Data_mining_lab1.pdf](Data_mining_lab1.pdf) | Clustering | HARTIGAN — nutrient levels of 27 foods |
| 2 | [Data_mining_lab2.pdf](Data_mining_lab2.pdf) | Clustering + association analysis to characterize the obtained clusters | Iris |
| 3 | [Data_mining_lab3.pdf](Data_mining_lab3.pdf) | Association analysis — mining frequent patterns and rules | Course datasets |

## Topics covered

- K-means / hierarchical clustering and cluster evaluation in Weka
- Using association analysis to *describe and interpret* clusters
- Frequent-pattern mining and rule generation
